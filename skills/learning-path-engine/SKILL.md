# Learning Path & Pedagogical Sequence Engine

Specialized skill for structuring technical learning journeys, calibrating cognitive load, designing progressive milestones, and verifying learner onboarding prerequisites.

---

## 1. Pedagogical Scaffolding & Pacing

1. **Prerequisite Transparency**: Clearly state mandatory tools, language versions, and foundational knowledge before instruction begins.
2. **Cognitive Chunking**:
   - Limit each tutorial chapter to one core conceptual breakthrough.
   - Ideal reading time per chapter: 8–15 minutes with measurable checkpoints.
3. **Milestone Badging**:
   - Accompany each step with visual progress markers (`Step 1 of 4`, `Step 2 of 4`).
   - Conclude each section with a tangible "Checkpoint: What You Have Built So Far".
4. **Error Recovery Pathways**:
   - Anticipate common failure modes and provide explicit "Troubleshooting & Gotchas" callouts directly following risky commands.

---

## 2. Structural Roadmap Pattern

```markdown
### 🗺️ 本教程学习路径图
1. 🏁 基础配置与依赖注入 (10 min)
2. ⚡ 异步状态流与核心 Pipeline (15 min)
3. 🛡️ 容错重试与背压保护 (12 min)
4. 🚀 部署验证与全链路可观测性 (8 min)
```

---

## 3. Review Checklist

- [ ] Clear learning prerequisites with minimum required runtime versions (e.g. Node 20+, .NET 8).
- [ ] Each section builds incrementally upon the previous step without unexplained jumps.
- [ ] Explicit checkpoint or expected result validates success before moving to the next chapter.
- [ ] Previous / Next navigation connects adjacent learning milestones seamlessly.
