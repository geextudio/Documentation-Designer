# Documentation Quality Scoring Rubric (0–100)

A standardized multidimensional rubric to grade tutorials and documentation generated by Documentation Designer Pro.

---

## Dimension Breakdown

| Dimension | Weight | Target Standards |
| :--- | :--- | :--- |
| **1. Visual Aesthetics & Palette** | 20 pts | Modern SaaS design, low-glare dark/light palette, WCAG 2.1 AA/AAA contrast ($\ge 4.5:1$), harmonious code syntax theme, unified semantic callouts. |
| **2. Reading Flow & Typography** | 20 pts | Golden line measure ($60–75\text{ch}$), line height $1.7–1.8$, clear vertical rhythm, scannable H1–H3 hierarchy, cognitive chunking ($\le 4$ sentences/paragraph). |
| **3. Pedagogical Structure** | 20 pts | 4-step execution rhythm (Intent $\rightarrow$ Prereq $\rightarrow$ Code/Action $\rightarrow$ Verified Outcome), learning goals box, estimated time badge, progressive deep-dives. |
| **4. Multi-Screen Responsiveness** | 20 pts | 3-column desktop to 1-column mobile reflow, zero horizontal window spill, isolated code/table scrolling, mobile bottom thumb bar, touch targets $\ge 44\text{px}$. |
| **5. Technical Accuracy & Dual Formats** | 20 pts | Complete semantic Markdown output + standalone self-contained `index.html` with theme switcher, progress bar, copy-to-clipboard, and Mermaid diagrams. |

---

## Grading Tiers

- **90–100 (Enterprise Gold Standard)**: Flawless visual design, fluid multi-screen responsiveness, rich interactive aids, zero layout bugs, full WCAG compliance, complete dual outputs.
- **80–89 (Production Ready)**: Strong typography and color palette, good responsive behavior with minor styling opportunities.
- **70–79 (Acceptable)**: Functional tutorial but lacks modern visual polish or exhibits line measure stretching on wide screens.
- **< 70 (Needs Revision)**: Fails responsiveness, insufficient contrast, or missing execution/verification steps.
